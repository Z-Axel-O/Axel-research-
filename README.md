# Axel's Research — Demo MVP

Open `index.html` locally, or deploy the two files to a public GitHub repository with GitHub Pages (Settings → Pages → Deploy from main/root).

## Working features
- Searchable 12-stock simulated universe
- Filter by RSI, market cap, sector, research score and screening presets
- Calculated Wilder RSI(14), MACD(12,26,9), Bollinger Bands(20,2), SMA50 and SMA200 on synthetic price series
- Transparent weighted score, factor breakdown and CSV export
- Responsive desktop/mobile dashboard

## Important limitations
**All prices, P/E ratios, fundamental scores and price histories are fictional demo values.** No live API, financial statements, backtesting, accounts, notifications, or AI model are connected. Not for investing decisions.
